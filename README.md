# ssb-practice


A simple, timed practice site for SSB (Services Selection Board) psychology tests. No install, no backend: just open `index.html`.

## Tests and timings
| Test | Timing |
|---|---|
| PPDT | 30 s view, 4 min write |
| TAT | 12 slides (last blank), 30 s view, 4 min write each |
| WAT | 60 words, 15 s each |
| Lecturette | 3 min prepare, 3 min speak (4 topics) |

## Add your pictures
Put images in `images/` named `pic1.jpg` to `pic12.jpg` (pic12 is not shown; TAT slide 12 is blank). Use your own sketches or free-licence images (Unsplash, Pexels, Pixabay). Do not use copyrighted test material.

## Run locally
Open `index.html` in a browser.

## Host free with GitHub Pages
Repo Settings > Pages > Deploy from branch > `main` / root.

## Customise
Edit the `WORDS` and `TOPICS` lists in `index.html`.
